# 양자화 Quantization

양자화(Quantization)는 딥러닝 모델의 연산 속도를 높이고 메모리 크기를 줄이기 위해, 연산에 사용되는 소수점(부동소수점) 데이터를 더 작은 비트의 정수 데이터로 변환하는 기술입니다.
NPU의 동작 구조(시스톨릭 어레이)와 결합했을 때 성능을 극대화하는 핵심 치트키입니다.

---

## 1. 양자화의 기본 원리: FP32에서 INT8로

일반적으로 AI 모델을 학습시킬 때는 정밀도를 위해 32비트 부동소수점(FP32)을 사용합니다. 하지만 NPU에서 추론(Inference)을 할 때는 이를 8비트 정수(INT8)나 그 이하로 변환합니다.

* FP32: 표현할 수 있는 숫자의 범위가 엄청나게 넓지만, 그만큼 컴퓨터가 계산하기 무겁습니다.
* INT8: -128부터 127(또는 0부터 255)까지의 정수만 표현합니다.
* 변환 과정: FP32의 최소/최대 범위를 INT8의 -128 ~ 127 구간에 일정한 간격(Scale)으로 매핑(Mapping)하여 꾹꾹 눌러 담는 방식입니다.

---

## 2. 양자화가 NPU 성능을 극대화하는 이유 (3대 효과)

   1. 메모리 대역폭(Bandwidth) 절약 (용량 1/4 축소)
   * 데이터 크기가 32비트에서 8비트로 줄어들면, 모델의 용량이 4분의 1로 줄어듭니다.
      * 온칩 메모리(SRAM)에 더 많은 가중치를 올릴 수 있어 외부 DRAM을 왕복하는 횟수가 급감합니다.
   2. 연산 속도(Throughput) 폭발적 증가
   * NPU 내부에 있는 계산기(PE) 입장에서 FP32 곱셈보다 INT8 곱셈이 훨씬 단순합니다.
      * 하드웨어 칩 내부에서 같은 면적당 더 많은 INT8 계산기를 배치할 수 있어, 초당 처리할 수 있는 연산 횟수(TOPS)가 수배 이상 뜁니다.
   3. 소모 전력 감소
   * 정수 연산은 부동소수점 연산보다 전력 소모가 훨씬 적습니다. 스마트폰이나 자율주행차 같은 온디바이스 AI 환경에서 배터리를 크게 아낄 수 있습니다.
   
---

## 3. 양자화의 두 가지 접근 방식

데이터를 압축하다 보면 필연적으로 미세한 오차가 발생하여 모델의 정확도가 떨어질 수 있습니다. 이를 해결하기 위해 두 가지 방법을 씁니다.

[ 학습 완료된 FP32 모델 ]
       │
       ├─► (PTQ: 바로 정수로 변환) ──────────► [ 가볍지만 정확도 약간 하락 ]
       │
       └─► (QAT: 오차를 고려해 재학습) ──────► [ 정확도 유지, 추가 비용 발생 ]


* PTQ (Post-Training Quantization, 학습 후 양자화)
* 방식: 이미 학습이 끝난 모델을 준비된 데이터를 바탕으로 스케일만 조절해 바로 INT8로 변환합니다.
   * 장점: 수 시간 내에 빠르게 처리가 가능합니다.
   * 단점: 모델에 따라 정확도 손실이 발생할 수 있습니다.
* QAT (Quantization-Aware Training, 양자화 인식 학습)
* 방식: 모델을 학습시킬 때부터 "이 모델은 나중에 정수로 바뀔 것"을 가정하고 가상의 양자화 오차를 주입하며 학습시킵니다.
   * 장점: 변환 후에도 FP32 모델과 거의 동일한 최상의 정확도를 유지합니다.
   * 단점: 모델을 처음부터 다시 학습시키거나 파인튜닝해야 하므로 컴퓨팅 자원과 시간이 많이 듭니다.

---

## 4. 최신 트렌드: INT4를 넘어 FP4/NF4까지

최근 ChatGPT, Llama 같은 거대 언어 모델(LLM)이 대세가 되면서 양자화 기술은 더욱 극단적으로 발전하고 있습니다.

* INT4 양자화: 데이터를 고작 4비트(0~15)로 줄여버립니다. 용량이 8분의 1로 줄어들어 모바일 기기에서도 거대 모델을 돌릴 수 있게 만듭니다.
* 혼합 정밀도(Mixed Precision): 중요도가 높은 파라미터는 FP16이나 INT8로 남겨두고, 덜 중요한 파라미터만 4비트 이하로 줄여 정확도 하락을 방지합니다.

---

NPU 하드웨어가 아무리 좋아도 소프트웨어적인 양자화 기술이 뒷받침되지 않으면 거대한 AI 모델을 효율적으로 구동할 수 없습니다.
혹시 관련해서 다음 내용 중 더 구체적으로 알고 싶으신 부분이 있으신가요?

* 양자화 과정에서 데이터 범위를 정하는 캘리브레이션(Calibration) 방법
* AI 개발 시 자주 쓰이는 양자화 프레임워크(TensorRT, PyTorch Quantization 등)
* LLM 구동에 특화된 최신 기술인 AWQ나 GPTQ 알고리즘
