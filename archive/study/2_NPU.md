# NPU 동작 구조

NPU(Neural Processing Unit, 신경망처리장치)는 인공지능의 핵심인 대규모 행렬 곱셈(MAC 연산)을 한 번에 동시에 (병렬로) 초고속 처리하기 위해 설계된 특화 반도체입니다.
순차 연산에 최적화된 CPU나 그래픽 출력에 맞춘 GPU와 달리, NPU는 수천 개의 계산기가 동시에 그물망처럼 움직이는 구조를 가집니다.

---

## 1. 핵심 동작 구조: 시스톨릭 어레이 (Systolic Array)
NPU 구조의 핵심은 시스톨릭 어레이(Systolic Array) 구조입니다. 심장이 피를 펌프질하듯 데이터를 규칙적으로 밀어내며 연산하는 방식입니다.

* PE (Processing Element) 배열: NPU 내부에는 MAC 연산(곱셈+덧셈)만 수행하는 작은 계산기(PE)가 바둑판 형태로 수천 개 배열되어 있습니다.
* 메모리 병목 해결: CPU는 메모리에서 데이터 가져오기 → 계산 → 메모리에 저장을 반복하느라 속도가 느려집니다. 반면, NPU는 인접한 PE끼리 계산된 중간 결과값을 메모리 거치지 않고 옆으로 바로 전달합니다.
* 효과: 메모리 접근 횟수가 극적으로 줄어들어 전력 소모가 낮아지고 연산 속도가 폭발적으로 증가합니다.

---

## 2. NPU 내부의 데이터 흐름 (3단계)

인공지능 모델이 추론(Inference)을 수행할 때 NPU 내부에서는 다음과 같이 데이터가 흐릅니다.

[가중치(Weight) 버퍼] ──┐
                         ▼
[입력 데이터 버퍼] ───► [ PE 가속기 배열 (MAC 연산) ] ───► [액티베이션 및 풀링] ───► [출력]


   1. 데이터 로드 (Weight & Input)
   AI 모델의 뼈대인 가중치(Weight)와 사용자가 입력한 데이터(이미지, 텍스트 등)가 NPU 내부의 고속 임시 메모리(SRAM)에 적재됩니다.
   2. 병렬 가중합 연산 (MAC)
   수천 개의 PE가 동시에 입력값 × 가중치 + 이전 결과값을 계산합니다. 거대한 행렬 곱셈이 단 몇 사이클 만에 완료됩니다.
   3. 활성화 함수 및 결과 출력
   계산된 가중합 결과에 ReLU나 시그모이드 같은 활성화 함수(Activation Function)를 적용하여 비선형성을 더한 뒤, 최종 출력을 내보내거나 다음 신경망 레이어로 전달합니다.

---

## 3. CPU / GPU / NPU 구조 비교

| 구분 | CPU (중앙처리장치) | GPU (그래픽처리장치) | NPU (신경망처리장치) |
|---|---|---|---|
| 코어 구조 | 고성능 코어 소수 (2~16개) | 범용 코어 다수 (수천 개) | AI 특화 PE 수천~수만 개 |
| 처리 방식 | 복잡한 명령 직렬 처리 | 그래픽·연산 병렬 처리 | 행렬/벡터 연산 초병렬 처리 |
| 유연성 | 매우 높음 (모든 작업 가능) | 높음 (다목적 연산 가능) | 낮음 (AI 연산만 전용) |
| 효율성 | AI 연산 시 전력·속도 저하 | 성능은 좋으나 전력 소모 큼 | 압도적인 전력 대비 성능비 |

---

## 4. NPU 컴파일러의 역할 (하드웨어만큼 중요한 소프트웨어)
NPU가 제 성능을 내려면 컴파일러(Compiler)의 역할이 절대적입니다.
PyTorch나 TensorFlow 같은 프레임워크로 만든 AI 모델을 NPU 하드웨어가 이해할 수 있는 최적의 명령어 형태로 쪼개고, 데이터가 끊기지 않게 PE 배열에 골고루 분배해 주는 소프트웨어 지휘자 역할을 합니다.

---

NPU의 하드웨어 구조에 대해 더 깊이 이해하시는 데 도움이 되었기를 바랍니다.
만약 관심이 있으시다면 다음 주제 중 어떤 것을 더 알아보고 싶으신가요?

* 구글 TPU나 애플 Neural Engine 같은 실제 기업들의 NPU 칩 구조 차이
* NPU 성능을 극대화하기 위해 데이터 크기를 줄이는 양자화(Quantization) 기술
* 대형 언어 모델(LLM) 구동에 특화된 최신 NPU 트렌드

# 대형 언어 모델(LLM) 구동에 특화된 최신 NPU 트렌드

대형 언어 모델(LLM)과 생성형 AI의 폭발적인 성장으로 인해 하드웨어 시장 역시 급격한 변화를 맞이하고 있습니다. 과거에는 딥러닝 연산을 위해 단순히 '더 많은 연산 능력(TOPS)'만 강조했다면, 최신 NPU 트렌드는 LLM의 독특한 병목 현상을 해결하는 방향으로 진화하고 있습니다.
현재 시장을 주도하고 있는 핵심 NPU 트렌드를 클라우드(서버형)와 온디바이스(기기 탑재형) 두 영역으로 나누어 정리해 드립니다.

---

## 1. 클라우드/대형 서버 NPU: "Inference(추론)와 Training(학습)의 분리"

과거에는 하나의 AI 가속기(GPU/NPU)로 학습과 추론을 모두 처리하려 했습니다. 하지만 LLM 시대에 접어들며 두 작업의 병목 지점이 완전히 다르다는 것을 깨닫고, 하드웨어 칩 자체를 이원화(Split)하는 구조가 트렌드로 자리 잡았습니다.

* 학습(Training)용 칩과 추론(Inference)용 칩의 설계 분리
* 구글의 최신 TPU v8(구글의 커스텀 NPU) 라인업은 학습용인 v8t와 추론용인 v8i로 아예 칩을 쪼개어 출시했습니다.
   * 학습에는 엄청난 연산 성능(FLOPS)이 필요하지만, 이미 서비스 중인 LLM을 구동(추론)할 때는 연산 능력보다 '토큰당 비용(Cost-per-token)'과 전력 효율이 중요하기 때문입니다.
* 초고대역폭 메모리(HBM) 및 고속 인터커넥트의 결합
* LLM은 매개변수가 너무 커서 칩 내부 메모리에 다 들어가지 않습니다. 따라서 메모리에서 데이터를 읽어오는 속도가 전체 NPU 속도를 결정합니다.
   * 최신 NPU들은 초고속 메모리인 HBM3e 및 HBM4를 칩 옆에 밀착시키고, 칩과 칩 사이를 광학 스위치나 고속 버스(ICI)로 직접 연결하여 메모리 병목을 극복하고 있습니다.

---

## 2. 온디바이스(PC/모바일) NPU: "소형 언어 모델(sLM)의 로컬 구동"

2026년 현재 PC와 스마트폰 시장의 가장 큰 화두는 인터넷 연결 없이 기기 자체에서 AI를 돌리는 온디바이스 AI(On-device AI)입니다. 이를 위해 NPU는 LLM의 특성을 반영해 진화 중입니다.

* TOPS(연산 성능) 경쟁을 넘어 메모리 대역폭(Memory Bandwidth) 중심으로 전환
* 퀄컴 스냅드래곤 X2 엘리트, 인텔 코어 울트라(루나 레이크/팬서 레이크), AMD 라이젠 AI 400 시리즈 등 최신 칩셋들은 기본적으로 40~80 TOPS 수준의 강력한 NPU 성능을 제공합니다.
   * 하지만 실제 로컬에서 LLM(예: Llama 3 8B, Qwen 2.5 등)을 돌려보면 NPU의 연산 속도가 아니라 메모리 버스 대역폭에서 병목이 생깁니다. 따라서 최근에는 단순 NPU 스펙 업그레이드보다 LPDDR5X-8000 이상의 광대역 시스템 메모리 매칭을 강조하는 추세입니다.
* 트랜스포머 디코딩(Decoding) 병목 해결을 위한 이기종 컴퓨팅
* LLM 구동은 질문을 한 번에 읽는 '프리필(Prefill) 단계'와 답변을 한 글자씩 생성하는 '디코딩(Decoding) 단계'로 나뉩니다.
   * NPU는 구조상 덩치가 큰 연산(프리필)은 아주 잘하지만, 실시간으로 한 단어씩 출력하는 잔잔한 연산(디코딩)에서는 오히려 CPU나 GPU보다 비효율적일 수 있습니다.
   * 이를 해결하기 위해 최신 모바일/PC 구동 시스템은 프리필은 NPU가 담당하고 디코딩은 CPU/GPU가 이어받는 동적 오프로딩(Offloading) 및 스케줄링 기술을 탑재하고 있습니다.

---

## 3. 소프트웨어 최적화: 알고리즘의 하드웨어 네이티브화
NPU 하드웨어 구조가 발전하면서, LLM 성능 향상을 위해 쓰이던 핵심 소프트웨어 알고리즘들이 아예 NPU 하드웨어 명령어 수준에서 기본 지원되기 시작했습니다.

* 플래시어텐션(FlashAttention) 및 페이지드어텐션(PagedAttention) 하드웨어 가속
* LLM의 핵심 아키텍처인 '어텐션(Attention)' 연산 시 메모리 낭비를 줄여주는 기술들입니다.
   * 리벨리온(Rebellions) 등 국내외 주요 NPU 스타트업과 빅테크 기업들은 가상 메모리 관리 기법인 PagedAttention 등을 NPU 전용 런타임에 네이티브하게 통합하여 GPU 대비 압도적인 가성비로 LLM 서비스를 서빙(Serving)하고 있습니다. [18, 19] 
* FP4 / NF4 초저비트 양자화 연산 유닛 탑재
* 8비트 정수(INT8) 수준을 넘어, 엔비디아 블랙웰(Blackwell) 아키텍처나 최신 NPU들은 4비트 부동소수점(FP4) 연산 유닛을 하드웨어 코어에 직접 내장하고 있습니다.
   * 이를 통해 정확도 손실을 최소화하면서 LLM 모델의 용량을 8분의 1로 압축해 초고속 추론을 구현합니다.

----

요약하자면, 최신 NPU는 단순히 "계산이 빠르다"를 넘어 "대규모 가중치를 가진 LLM 모델을 어떻게 메모리 병목 없이, 가장 저렴한 비용과 적은 전력으로 구동할 것인가"에 초점을 맞추어 아키텍처(구조)와 메모리, 소프트웨어가 삼박자로 결합되는 형태로 발전하고 있습니다.
이 트렌드와 관련하여 국내 NPU 기업(리벨리온, 퓨리오사AI 등)의 LLM 특화 칩 성능이나 엔비디아 GPU와 NPU의 LLM 구동 효율 차이 등 더 알고 싶으신 부분이 있다면 질문해 주세요!
